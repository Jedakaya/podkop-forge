# Podkop Forge

Форк [podkop-evolution](https://github.com/yandexru45/podkop-evolution) → [itdoginfo/podkop](https://github.com/itdoginfo/podkop) с доработками и исправлениями под реальные сценарии использования.

## Установка

```sh
sh <(wget -O - https://raw.githubusercontent.com/Jedakaya/podkop-forge/refs/heads/main/install.sh)
```

Требования: **OpenWrt 24.10+**, минимум 25 МБ свободного места.

> После обновления обязательно [сбросьте кэш LuCI](https://podkop.net/docs/clear-browser-cache/).

## Что добавлено и исправлено

### Подписки

- **Загрузка через прокси** (`download_lists_via_proxy=1`) — `curl` вместо `wget`, автоматический фоллбэк на прямое соединение если сервер подписки недоступен через прокси
- **Happ-формат** — разбор JSON-массива Xray-конфигов: vless (XHTTP / Reality / TLS), Hysteria2
- **User-Agent** по умолчанию — `Happ/4.10.2/ios/...` (у большинства провайдеров даёт наиболее полный формат с Hysteria2 и XHTTP); настраивается через `subscription_user_agent`
- **XHTTP-серверы** из подписки
- **gzip-подписки** корректно распаковываются
- **Дашборд**: трафик и срок действия подписки, кнопка ручного обновления

### DNS

- **DNS failover** — при блокировке настроенного DNS (DoH/DoT) автоматически переключается на UDP-резервы (`77.88.8.8` → `1.1.1.1` → `8.8.8.8`); включён по умолчанию (`enable_dns_failover=1`); возврат к оригинальному DNS — только вручную командой `podkop dns_failover_retry_original`; **для локальных адресов (127.x, 192.168.x, 10.x и т.п.) failover не срабатывает** — локальный DNS (AdGuard Home, Pi-hole) не может быть заблокирован провайдером

### Стабильность

- **Lifecycle lock** (v0.7.43) — устраняет гонку между стартом podkop и BadWAN-триггером при загрузке роутера; после перезагрузки FakeIP поднимается без ручного вмешательства
- **Диагностика**: корректная проверка версии sing-box-extended 1.13.x+
- **Hysteria2 из подписки**: убран uTLS fingerprint, несовместимый с QUIC

## Если что-то не работает

[Страница диагностики](https://podkop.net/docs/diagnostics/) — первый шаг.

При обновлении с версии ниже 0.7.0 структура конфига изменилась — скрипт установки предупредит об этом автоматически.
